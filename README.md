# 复习航线 · 00504 艺术概论

这是一个面向辽宁省沈阳自考本科 00504《艺术概论》的个人复习网页原型。

## 运行

在当前目录启动静态服务：

```powershell
python -m http.server 4173
```

## 跨设备同步

在“课程设置 → 数据管理”中设置同步码。电脑和手机输入同一个同步码后，学习记录会自动保存到 Cloudflare 同步服务；也可以使用“读取云端进度”恢复另一台设备的最新记录。

同步码相当于访问凭证，请不要分享给其他人。更新项目之前仍建议先点击“创建存档”并导出 JSON 备份。

然后打开 `http://127.0.0.1:4173/`。

## 当前内容

- 9章课程地图与60天首轮学习、28天循环复习计划。
- 每天只推进当前计划章节，学习17条可直接用于考试的重点结论。
- 同一组17题练三轮：第一轮遮2处、第二轮遮3处、第三轮遮4处，后两轮自动打乱题序。
- 选词填空包含同章节、长度接近和概念相近的干扰项，避免只靠排除无关答案。
- 答题后在桌面右侧固定显示完整答案、具体例子和原因，不再展开题卡或显示记忆关键词。
- 学习进度、经验值、错题和复习次数使用浏览器 `localStorage` 保存。
- 页面支持桌面端和 `max-width: 800px` 移动端布局。
- [schedule.json](schedule.json) 保存88天排课阶段、学习日/复习日和每日任务类型。

## 每日答题闯关

完成当天17条结论的三轮练习后，可选择立即进入或稍后进入原创像素风关卡：

- 开局5颗心、3张提示卡、20个答案碎片；
- 至少12个可跳跃触发的问号方块；
- 小怪用子弹击杀，中怪和两个普通Boss使用答案碎片战斗；
- 最终“默写终审官”固定5滴血，只能默写作答；
- 默写不要求逐字一致，按核心意思和语义相似度判定；
- 电脑支持方向键、空格和F键，手机提供触屏控制；
- 每天根据日期生成不同但可恢复的固定关卡。
- 怪物战斗只读取当天练习的17条答案，不会混入其他章节。
- 首次升级到三轮模式时会保留旧版当日任务副本，经验值、错题、同步码和历史数据不会被清空。

## 内容边界

当前版本使用老师提供的建筑艺术小范围资料与整理后的 00504 基础理论题目。游戏中的默写判定在浏览器本地完成，没有调用在线 AI 服务。题库和同义表达仍可随真实学习反馈继续扩充。
