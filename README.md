## 每日学习

- 全课程9章，首轮学习60天，循环复习28天。
- 每天10个不同知识点：7道当前章节题 + 3道错题或旧章节复习题。
- 同一组10题练三轮，共30次提取练习。
- 第一轮遮2处、第二轮遮3处、第三轮遮4处；后两轮自动打乱题序。
- 选项包含概念相近的干扰项；并列答案支持顺序不限。
- 桌面端答题后在右侧显示完整答案、具体例子和解析，题目区域不会被向下撑开。
- 错题可查看完整记录、错误次数和正确答案，并可重新作答。

## 艺术博物馆冒险

完成当天三轮练习后解锁 Phaser 3 全屏横版关卡：

- 原创16位像素角色与艺术博物馆场景；
- 电脑支持方向键/A/D、空格、F/J；手机支持横屏触控；
- 开局5颗心、3张提示卡、10个答案碎片；
- 10个问号方块，可获得生命、护盾、提示或答案碎片；
- 小怪用子弹击杀并掉落1—2个碎片；
- 中怪和两名守关Boss使用带下划线的答案槽拼接作答；
- 两名守关Boss均击败后，才能挑战5血默写终Boss；
- 默写标准答案必定通过；非逐字答案按核心含义判断。

## 数据安全

- 每次选词、提交、换题、战斗和领取奖励后自动保存到浏览器。
- 刷新、关闭页面或升级版本不会主动清空进度。
- 设置页支持导出/导入 JSON、创建版本存档和恢复存档。
- 清除进度仅位于设置页危险区域，并要求二次确认。
- 电脑和手机填写同一个同步码后，可通过 Cloudflare Worker 同步同一份进度。

## 本地运行

```powershell
python -m http.server 4173
```

打开 `http://127.0.0.1:4173/`。
